# Insurance_Analysis
## 📊 Project Overview

This project is a **Power BI practice project** focused on analyzing insurance policies, premium amounts, coverage amounts, and claim performance.

The dashboard provides interactive insights into **policy status, policy types, claim status, customer demographics, and claim amounts**. A **Drill-through page** is also implemented for detailed analysis of the **Travel policy type**.

---

## 🎯 Objectives

- Analyze total premium and coverage amounts
- Identify active and inactive policies
- Analyze premium amounts by policy type
- Analyze claims by claim status
- Analyze claim amounts across different age groups
- Compare pending, rejected, and settled claim amounts
- Provide detailed policy-level information using Drill-through

---

## 🛠️ Tools & Technologies

- **Power BI**
- **Power Query**

## 🔍 Drill-through Analysis

A **Drill-through page** has been created for the **Travel policy type**.

Users can select the Travel policy type from the main dashboard and navigate to a detailed page containing individual policy records.

### Travel Policy Details

The drill-through page includes:

- Policy Number
- Customer ID
- Age
- Gender
- Policy Type
- Policy Start Date
- Policy End Date
- Coverage Amount
- Premium Amount
- Claim Amount
- Claim Status
- Claim Date
- Claim Number

## 📈 Key Insights

- **Travel policies** generate the highest premium amount among the analyzed policy types.
- The majority of policies are **active**, while a smaller percentage are inactive.
- **Rejected claims** have the highest claim count compared with settled and pending claims.
- Claim amounts differ across **Adult, Elder, and Young Adult** age groups.
- Policy type-wise analysis provides a clear comparison of **pending, rejected, and settled claim amounts**.
